## Release boundaries

Wave 2 delivers the connected research/data/model/product/compute/competition loop. The first-sale path remains intact. An earned deployment milestone remains achieved while a replacement model is being deployed.

Agents, player enterprise/private contracts, weight licensing, custom chips, later research applications, victory routes, and complete campaign balance remain subsequent waves. Behavioral calibration is implemented; general autonomous-goal misalignment and security-incident systems are not. The rival policy is a bounded strategy heuristic with explicit one-time starting assets.

Local saves remain specific to the current browser. Export/import provides portability; this release does not add account-synchronized saves or offline progression. All prices, workloads, scores, capacities and populations are game coefficients.
